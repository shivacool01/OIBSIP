🌡️ OIBSIP Level 1 – Task 3  
Temperature Converter

This project is created as part of the **Oasis Infobyte Web Development Internship (OIBSIP)**.

The task was to build a **Temperature Converter** using **HTML, CSS, and JavaScript**, where users can convert values between different temperature units.

---

## 🔧 Features
- Convert temperature between:
  - Celsius
  - Fahrenheit
  - Kelvin
- Single input field with selectable units
- Clean and modern UI
- Displays the calculated result clearly
- Shows the conversion formula used

---

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript
